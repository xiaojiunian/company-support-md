## Canopy Support 是什么

Canopy Support 是面向客户支持与产品使用说明的文档中心，用来集中展示产品介绍、操作指南、常见问题和集成说明。

## 适合放哪些内容

这里可以放新用户入门说明、功能模块概览、账号与权限说明、数据集成步骤，以及团队经常被问到的产品问题。

## 当前文档如何更新

文档内容由 GitHub 中的 Markdown 文件维护。每次推送更新后，系统会校验 frontmatter 和正文格式，通过后自动转换为页面可展示的 HTML。
